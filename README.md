# Mackenzie-Portfolio
## Reflection
One thing I didn’t understand at first was why Git required me to pull the remote repository before pushing my local files. When I tried to push, Git showed an error about unrelated histories. I asked the agent to explain it, and learned that GitHub had already created an initial commit for the README, so my local project didn’t match the remote history. The agent explained that pulling with --allow-unrelated-histories merges the two histories safely. After that, I understood how Git tracks versions and why syncing matters before pushing changes.
