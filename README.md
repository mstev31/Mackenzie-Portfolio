# Mackenzie Stevens — Personal Portfolio Website

This repository contains the source code for my personal portfolio website, built as part of the ISDS 4125 Vibe Coding Exercise. The site uses a hybrid layout with a single-page home (Profile, Skills, Experience, Contact) and two expanded subpages: Resume and Project. All pages share a consistent design and styling through a unified CSS file.

## Live Website
https://mackmakingstuff.com/Mackenzie-Portfolio/

## Reflection
One specific thing I learned during this project was how Antigravity handles content generation when instructions are not extremely precise. At first, the agent kept adding invented details to my Skills and Experience sections, such as years of experience or metrics that were not real. I didn’t understand why this was happening, so I asked the agent to explain its behavior. I learned that unless I explicitly restrict the agent to “use only the information I provide,” it will try to enhance sections with filler content. After understanding this, I began giving very strict instructions, and the agent updated my pages correctly using only my real resume and project details. This helped me understand how important clear, directive prompting is when working with AI coding tools.
